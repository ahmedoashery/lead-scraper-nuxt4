# Nuxt 4 + Nuxt UI 4 lead scraper app

This project contains a lead scraper control dashboard that sends form values to an n8n webhook as a background automation trigger.

## Setup

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Features

- Nuxt 4 app shell
- Nuxt UI 4 components
- Dynamic configuration form for niche, city, lead limit, and n8n webhook URL
- Success/error status toast messaging
- Form submission to a configured n8n webhook endpoint
